# Rome trip planner, 14–18 October 2026

Static one-page itinerary with map, prices and official ticket links.

- `index.html`, `styles.css`, `app.js` – the page
- `data.js` – places, itinerary, budget and sources (edit this to change the plan)
- `docs/superpowers/specs/` – design note

Run locally: `npx serve .` and open http://localhost:3000.

Deploy: `npx vercel login` once, then `npx vercel --prod`.
